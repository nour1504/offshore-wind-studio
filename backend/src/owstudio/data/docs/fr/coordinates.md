title: Importer les coordonnées
section: Parcs éoliens

summary: Coller ou importer des positions d'éoliennes (degrés, UTM ou EPSG) et vérifier l'aperçu avant de les ajouter.
related: getting-started, namelists, results
---

Coller les coordonnées d'une feuille de calcul ou les saisir sur la carte, puis définir l'ordre latitude/longitude ou longitude/latitude. Pour des coordonnées projetées, indiquer le code EPSG ou la zone UTM et l'hémisphère.

Contrôler l'aperçu avant d'ajouter ou remplacer des éoliennes : nombre de points, position, identifiants et type d'éolienne. Un import ambigu doit être corrigé ; le système de coordonnées ne se déduit pas du seul nom d'un fichier.

Référence officielle : [WRF User Guide](https://www2.mmm.ucar.edu/wrf/site/documentation/users_guide/) · [WPS](https://www2.mmm.ucar.edu/wrf/site/documentation/users_guide/wps.html) · [WRF Physics](https://www2.mmm.ucar.edu/wrf/site/documentation/users_guide/physics.html).
