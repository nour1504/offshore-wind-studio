title: Importer les coordonnées
section: Parcs éoliens
order: 50
summary: Coller ou importer des positions d'éoliennes (degrés, UTM ou EPSG) et vérifier l'aperçu avant de les ajouter.
related: getting-started, namelists, results
---

Collez les coordonnées d'une feuille de calcul ou saisissez-les sur la carte. Définissez l'ordre latitude/longitude ou longitude/latitude. Pour des coordonnées projetées, indiquez le code EPSG ou la zone UTM et l'hémisphère.

Contrôlez l'aperçu avant d'ajouter ou remplacer des turbines. Vérifiez le nombre de points, la position, les identifiants et le type de turbine. Un import ambigu doit être corrigé ; ne déduisez pas le système de coordonnées seulement à partir du nom d'un fichier.

Référence officielle : [WRF User Guide](https://www2.mmm.ucar.edu/wrf/site/documentation/users_guide/) · [WPS](https://www2.mmm.ucar.edu/wrf/site/documentation/users_guide/wps.html) · [WRF Physics](https://www2.mmm.ucar.edu/wrf/site/documentation/users_guide/physics.html).
