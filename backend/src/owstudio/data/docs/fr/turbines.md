Un type de turbine contient sa hauteur de moyeu (m), diamètre (m), puissance nominale (MW), et une courbe vitesse (m/s), puissance (kW), coefficient de poussée Ct. Une turbine placée dans un parc référence le numéro de ce type.

Le catalogue indique la source des courbes. Vérifiez que la courbe correspond au modèle et à la configuration étudiés. Une courbe synthétique n'est pas une courbe fabricant. Un modèle utilisé par une implantation doit rester disponible.

Référence officielle : [WRF User Guide](https://www2.mmm.ucar.edu/wrf/site/documentation/users_guide/) · [WPS](https://www2.mmm.ucar.edu/wrf/site/documentation/users_guide/wps.html) · [WRF Physics](https://www2.mmm.ucar.edu/wrf/site/documentation/users_guide/physics.html).
