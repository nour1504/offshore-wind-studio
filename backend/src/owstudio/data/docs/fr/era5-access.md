Le téléchargement ERA5 utilise votre compte Copernicus CDS. Acceptez les conditions du jeu de données sur le site et saisissez votre clé dans Paramètres. Une clé n'est pas nécessaire pour importer des fichiers ERA5 déjà téléchargés.

Les téléchargements peuvent être longs ou soumis à file d'attente et quota. Vérifiez période, emprise, niveaux de pression et champs de surface/sol requis. Ne partagez pas votre clé avec un projet exporté.

Référence officielle : [WRF User Guide](https://www2.mmm.ucar.edu/wrf/site/documentation/users_guide/) · [WPS](https://www2.mmm.ucar.edu/wrf/site/documentation/users_guide/wps.html) · [WRF Physics](https://www2.mmm.ucar.edu/wrf/site/documentation/users_guide/physics.html).
