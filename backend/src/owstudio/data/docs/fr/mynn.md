`bl_pbl_physics=5` active MYNN. Les niveaux, le schéma de surface, les options de turbulence et le traitement de TKE doivent être compatibles avec l'étude et le schéma de parc.

MYNN peut fournir `QKE` (deux fois la TKE). La TI dérivée sous hypothèse d'isotropie n'est pas une TI LiDAR mesurée sur dix minutes. Les méthodes, unités et limites sont précisées dans [Intensité de turbulence](doc:turbulence-intensity).
