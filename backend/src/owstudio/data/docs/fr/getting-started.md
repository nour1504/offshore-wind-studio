Créer ou ouvrir un projet dans **Projets**, puis choisir sa période et ses données. Configurer ensuite les domaines, les parcs et leurs types d'éoliennes, la physique et les sorties. Les modifications restent dans un brouillon partagé ; **Enregistrer** sauvegarde le projet entier.

L'application s'ouvre et analyse des sorties existantes sans installation séparée de Python. Pour exécuter WPS/WRF, il faut un moteur de calcul : **Calcul > Installer un moteur** installe WRF 4.8.0 et WPS 4.7.0 sur ce PC (une Linux WSL dédiée) ou dans un dossier choisi d'un ordinateur Linux, puis configure le profil (voir [Installer le moteur](doc:engine-install)). Un profil peut aussi désigner un moteur installé à la main.

Avant d'exporter les fichiers WRF, vérifier les erreurs, le nombre de processus et l'estimation de volume. Les résultats, entrées et rapports ont des dossiers distincts visibles dans **Paramètres**. Un exemple de projet sert à préparer une étude ; il ne contient pas un an de résultats.

Référence officielle : [WRF User Guide](https://www2.mmm.ucar.edu/wrf/site/documentation/users_guide/) · [WPS](https://www2.mmm.ucar.edu/wrf/site/documentation/users_guide/wps.html) · [WRF Physics](https://www2.mmm.ucar.edu/wrf/site/documentation/users_guide/physics.html).
