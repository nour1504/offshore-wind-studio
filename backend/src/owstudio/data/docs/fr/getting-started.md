Créez ou ouvrez un projet dans **Projets**, puis choisissez sa période et ses données. Configurez les domaines, les parcs et leurs modèles de turbines, la physique et les sorties. Les modifications restent dans un brouillon partagé ; **Enregistrer** sauvegarde le projet entier.

L'application s'ouvre et analyse des sorties existantes sans installation séparée de Python. Pour exécuter WPS/WRF, il faut un moteur de calcul : **Calcul > Installer un moteur** installe pour vous WRF 4.8.0 et WPS 4.7.0 sur ce PC (une Linux WSL dédiée) ou dans un dossier choisi d'un ordinateur Linux, puis configure le profil (voir [Installer le moteur](doc:engine-install)). Un profil peut aussi désigner un moteur que vous avez installé vous-même.

Avant de lancer, vérifiez les erreurs, le nombre de processus et l'estimation de volume. Les résultats, entrées et rapports ont des dossiers distincts visibles dans **Paramètres**. Un exemple de projet sert à préparer une étude ; il ne contient pas un an de résultats.

Référence officielle : [WRF User Guide](https://www2.mmm.ucar.edu/wrf/site/documentation/users_guide/) · [WPS](https://www2.mmm.ucar.edu/wrf/site/documentation/users_guide/wps.html) · [WRF Physics](https://www2.mmm.ucar.edu/wrf/site/documentation/users_guide/physics.html).
