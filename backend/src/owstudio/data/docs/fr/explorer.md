Choix de la variable : **Vent et turbulence** regroupe les grandeurs calculées à partir des sorties (vent au moyeu, direction, intensité de turbulence...), **Variables de WRF** celles écrites telles quelles dans les fichiers d'historique (wrfout). La bulle à côté du nom donne sa définition. Un champ absent des sorties est signalé, jamais remplacé.

La carte montre la variable à l'instant choisi sur le curseur, à la hauteur donnée pour une variable en niveaux, dans le domaine choisi. Les dates sont en UTC.

Un clic sur la carte, ou un point des sorties tslist dans **Point**, donne la série de ce point dans **Au point** ; **Exporter** l'ouvre dans l'onglet [Exporter](doc:data-export). Avec un calcul sans éoliennes importé, **Sans éoliennes** montre les mêmes variables pour ce calcul témoin.

Référence officielle : [WRF User Guide](https://www2.mmm.ucar.edu/wrf/site/documentation/users_guide/) · [WPS](https://www2.mmm.ucar.edu/wrf/site/documentation/users_guide/wps.html) · [WRF Physics](https://www2.mmm.ucar.edu/wrf/site/documentation/users_guide/physics.html).
