WSL exécute le moteur Linux sur ce PC Windows. Indiquez la distribution et les chemins des installations existantes. Les fichiers Windows propres peuvent être lus via leur chemin WSL traduit.

WRF/WPS et leurs dépendances MPI/NetCDF doivent déjà fonctionner dans la distribution. Configurez l'environnement dans le profil, vérifiez-le, puis choisissez les ressources. Le disque virtuel WSL reste physiquement sur votre PC même si l'Explorateur l'affiche via un chemin réseau.

Référence officielle : [WRF User Guide](https://www2.mmm.ucar.edu/wrf/site/documentation/users_guide/) · [WPS](https://www2.mmm.ucar.edu/wrf/site/documentation/users_guide/wps.html) · [WRF Physics](https://www2.mmm.ucar.edu/wrf/site/documentation/users_guide/physics.html).
