Un projet rassemble les dates, domaines, données, parcs, modèles de turbines et namelists. Les pages éditent le même brouillon. **Enregistrer** conserve les changements ; **Abandonner** restaure la dernière version enregistrée.

Un paquet exporté garde une copie du projet enregistré. Modifier le projet ensuite ne le change pas. Chaque import de sorties a son dossier. Les avertissements doivent être examinés avant l'export.

Référence officielle : [WRF User Guide](https://www2.mmm.ucar.edu/wrf/site/documentation/users_guide/) · [WPS](https://www2.mmm.ucar.edu/wrf/site/documentation/users_guide/wps.html) · [WRF Physics](https://www2.mmm.ucar.edu/wrf/site/documentation/users_guide/physics.html).
