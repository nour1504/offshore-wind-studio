Une animation utilise les échéances réellement présentes dans wrfout. Réglages : domaine, variable, hauteur, plage, pas entre images et images par seconde. Les images sont rendues une à une ; la cadence vidéo ne modifie pas le pas de temps physique.

Un rapport rassemble le projet et sa période, les chiffres clés, la production, le vent et la configuration (domaines, parcs, physique, méthode) ; les namelists sont dans les fichiers exportés. Sans sorties, il reste un rapport de configuration. Contrôler la période couverte et les réserves scientifiques avant de partager.

Les exports ont des dossiers dédiés visibles dans Paramètres. L'annulation d'un rendu ne supprime pas les données WRF.

Référence officielle : [WRF User Guide](https://www2.mmm.ucar.edu/wrf/site/documentation/users_guide/) · [WPS](https://www2.mmm.ucar.edu/wrf/site/documentation/users_guide/wps.html) · [WRF Physics](https://www2.mmm.ucar.edu/wrf/site/documentation/users_guide/physics.html).
