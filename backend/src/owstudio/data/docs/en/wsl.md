WSL runs the Linux engine on this Windows PC. Set the distribution and paths of existing installations. Own Windows inputs can be read through translated WSL paths.

WRF/WPS and MPI/NetCDF dependencies must work in that distribution. Set environment commands, verify the profile, then choose resources. WSL virtual disks remain physically on your PC even when Explorer shows them through a network-style path.

Official reference : [WRF User Guide](https://www2.mmm.ucar.edu/wrf/site/documentation/users_guide/) · [WPS](https://www2.mmm.ucar.edu/wrf/site/documentation/users_guide/wps.html) · [WRF Physics](https://www2.mmm.ucar.edu/wrf/site/documentation/users_guide/physics.html).
