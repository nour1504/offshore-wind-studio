A project holds dates, domains, inputs, farms, turbine models and namelists. All pages edit the same draft. **Save** keeps changes; **Discard** restores the saved version.

An exported package keeps a copy of the saved project. Later edits do not alter it. Each import of outputs has its own folder. Review warnings before exporting.

Official reference : [WRF User Guide](https://www2.mmm.ucar.edu/wrf/site/documentation/users_guide/) · [WPS](https://www2.mmm.ucar.edu/wrf/site/documentation/users_guide/wps.html) · [WRF Physics](https://www2.mmm.ucar.edu/wrf/site/documentation/users_guide/physics.html).
