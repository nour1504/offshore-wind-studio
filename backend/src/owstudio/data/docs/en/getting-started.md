Create or open a project in **Projects**, then set its period and inputs. Configure domains, farms and turbine models, physics and outputs. Sections share one draft; **Save** stores the whole project.

The app opens and analyses existing outputs without a separate Python installation. Running WPS/WRF needs a compute engine: **Compute > Install an engine** installs WRF 4.8.0 and WPS 4.7.0 for you on this PC (a dedicated WSL Linux) or in a chosen folder of a Linux computer, then configures the profile (see [Installing the engine](doc:engine-install)). A profile can also point at an engine you installed yourself.

Before launching, review errors, process count and disk estimates. Input files, results and reports have separate folders shown in **Settings**. The example project is a configuration, not a year of results.

Official reference : [WRF User Guide](https://www2.mmm.ucar.edu/wrf/site/documentation/users_guide/) · [WPS](https://www2.mmm.ucar.edu/wrf/site/documentation/users_guide/wps.html) · [WRF Physics](https://www2.mmm.ucar.edu/wrf/site/documentation/users_guide/physics.html).
