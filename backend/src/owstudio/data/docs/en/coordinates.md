Paste spreadsheet coordinates or place points on the map. Set latitude/longitude versus longitude/latitude order. Projected coordinates need an EPSG code or UTM zone and hemisphere.

Check the preview before appending or replacing turbines. Verify count, location, identifiers and turbine type. Correct ambiguous imports; a file name alone cannot establish its coordinate system.

Official reference : [WRF User Guide](https://www2.mmm.ucar.edu/wrf/site/documentation/users_guide/) · [WPS](https://www2.mmm.ucar.edu/wrf/site/documentation/users_guide/wps.html) · [WRF Physics](https://www2.mmm.ucar.edu/wrf/site/documentation/users_guide/physics.html).
