A turbine type contains hub height (m), rotor diameter (m), rated power (MW), and a curve of speed (m/s), power (kW) and thrust coefficient Ct. Placed turbines refer to this type number.

The catalog provides curve sources. Check that each curve matches the turbine and operating configuration studied. A synthetic curve is not manufacturer data. Types used by a farm must remain available.

Official reference: [WRF User Guide](https://www2.mmm.ucar.edu/wrf/site/documentation/users_guide/) · [WPS](https://www2.mmm.ucar.edu/wrf/site/documentation/users_guide/wps.html) · [WRF Physics](https://www2.mmm.ucar.edu/wrf/site/documentation/users_guide/physics.html).
