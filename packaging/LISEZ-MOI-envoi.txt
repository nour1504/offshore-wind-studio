OFFSHORE WIND STUDIO {VERSION}
Version de démonstration en cours de validation

Ce dossier contient trois installateurs, selon l'ordinateur :
  - Windows 10 ou 11 :                                 OffshoreWindStudio-{VERSION}-setup.exe
  - Linux, avec le mot de passe administrateur :       offshore-wind-studio_{VERSION}_amd64.deb
  - Linux, sans mot de passe administrateur (travail) : OffshoreWindStudio-{VERSION}-linux-setup.run

INSTALLATION SOUS WINDOWS
1. Ouvrir OffshoreWindStudio-{VERSION}-setup.exe.
   L'installateur n'est pas encore signé : Windows peut afficher « Windows a protégé
   votre ordinateur » ou « Éditeur inconnu ». Vérifier d'abord que l'empreinte SHA256
   du fichier est bien celle indiquée en bas de ce document, puis cliquer sur
   « Informations complémentaires » et « Exécuter quand même ».
2. Suivre les étapes de l'installateur (aucun compte administrateur nécessaire).
3. Lancer Offshore Wind Studio depuis le menu Démarrer ou le Bureau.
Microsoft WebView2 est nécessaire pour la fenêtre ; l'installateur le vérifie et
l'installe au besoin (connexion Internet).

INSTALLATION SOUS LINUX (Debian, Scibian, Ubuntu et autres Linux 64 bits)
Avec le mot de passe administrateur : le fichier .deb
1. Double-cliquer sur offshore-wind-studio_{VERSION}_amd64.deb.
2. La logithèque s'ouvre : cliquer sur « Installer » et taper le mot de passe.
   (Sinon, dans un terminal : sudo apt install ./offshore-wind-studio_{VERSION}_amd64.deb)
3. Lancer Offshore Wind Studio depuis le menu des applications.
   Pour le désinstaller : la logithèque, ou sudo apt remove offshore-wind-studio.

Sans mot de passe administrateur : le fichier .run
1. Clic droit sur OffshoreWindStudio-{VERSION}-linux-setup.run, puis « Exécuter »
   (ou « Ouvrir avec… Exécuter »). Si rien ne se passe, dans un terminal ouvert
   dans ce dossier :
     sh OffshoreWindStudio-{VERSION}-linux-setup.run
2. Un message confirme l'installation (dans le dossier personnel).
3. Lancer Offshore Wind Studio depuis le menu des applications.
   Pour le désinstaller : « Désinstaller Offshore Wind Studio » dans le même menu.
Une nouvelle version remplace l'ancienne. Les projets (~/OffshoreWindStudio) et les
réglages (~/.config/OffshoreWindStudio) ne sont jamais supprimés.

Sous Linux, le logiciel s'ouvre dans sa propre fenêtre quand le Linux le permet,
sinon dans le navigateur (Firefox, Chrome…) : il se ferme alors avec le bouton
« Quitter » en bas du menu de gauche.

Sans rien d'autre à installer, le logiciel ouvre et prépare les projets
et analyse des sorties WRF existantes.

PROJET D'EXEMPLE
Ce dossier contient aussi un projet prêt à ouvrir :
{PROJETS}
À importer tel quel, sans le décompresser : dans le logiciel, Projets > Importer un
projet, puis ce fichier. Il contient case.yaml (le projet) et project.json (son
étiquette : version et date d'export). Il s'ouvre avec sa période, ses domaines, ses
parcs et ses réglages (sans calcul ni résultat).
Il utilise les données ERA5 : le script de téléchargement exporté demande un accès
Copernicus personnel sur la machine qui télécharge. Tout projet s'exporte de la même
façon (menu « … » d'un projet > Exporter) pour être envoyé à quelqu'un.

INSTALLATION DU MOTEUR DE CALCUL (WRF/WPS)
L'installation du moteur est facultative pour préparer les fichiers ou analyser les sorties.
Dans Calcul > Installer un moteur, deux cibles sont proposées :
  - Windows : la distribution Linux WSL dédiée ;
  - Linux : cet ordinateur, dans un dossier au choix, sans mot de passe administrateur.
La cible compatible avec le système est disponible. Le logiciel n'installe pas de
moteur à distance ; sur un cluster, le moteur est celui fourni par son administrateur.
L'assistant affiche les versions installées : WRF 4.8.0 et WPS 4.7.0 (sources
officielles ; WRF avec une seule modification, qui ajoute aux séries tslist la
puissance POWER, la TKE et les grandeurs de stabilité), compilateurs GNU 13.3.0,
OpenMPI 4.1.6, NetCDF 4.9.2 (C) et 4.6.1 (Fortran). Il vérifie la cible et l'espace
disque, puis télécharge et compile tout sur la cible, y compris la géographie
officielle du NCAR (2,8 Go à télécharger, environ 29 Go une fois décompressée).
À prévoir : environ 45 Go libres et 1 à 2 heures.
Sous Windows, une autorisation administrateur et un redémarrage peuvent être
demandés pour activer WSL. L'installation peut être fermée et reprise.
Le profil de calcul est ensuite configuré automatiquement.

PRÉPARER UN CALCUL
1. Enregistrer le projet et ouvrir Fichiers WRF.
2. Choisir Cluster (Slurm) ou Ordinateur Linux ; renseigner les chemins, les motifs
   des données et les ressources. Pour Slurm, adapter l'en-tête et les modules du cluster.
3. Extraire tous les fichiers ou Télécharger le zip. Le LISEZ-MOI du paquet donne
   l'ordre d'exécution, les dates UTC et les conventions des résultats.
4. Après calcul, importer le paquet ou son dossier wrf/ dans Résultats et énergie.
Le logiciel ne lance pas les simulations lui-même. Les scripts exportés exécutent
WPS année par année, puis les fenêtres WRF de la dernière à la première.

Ce dossier ne contient ni moteur, ni géographie, ni données météorologiques : le
moteur et la géographie sont téléchargés depuis leurs sources officielles à
l'installation du moteur, les données météorologiques par les scripts du calcul.
